## Bug interno emerso nella copertura shared

Il Connector installato dichiara inventario completo di 40 risorse (22 post e 18 documenti Elementor) ma esclude le 16 pagine pubblicate restituite dalla REST API WordPress. Il filtro `public=true AND publicly_queryable=true` omette le pagine native. Questo invalida la pretesa di copertura shared completa dell’inventario precedente.

Correzione repository nel Connector 1.3.4: selezione pubblica più `is_post_type_viewable`, secondo [la semantica WordPress](https://developer.wordpress.org/reference/functions/is_post_type_viewable/). Test comportamentale PHP copre inventario legacy/paginato, lettura reference di una pagina, esclusione draft/tipi nascosti/privati/filtrati, permessi e fail-closed. Versione pacchetto e runtime allineate a 1.3.4. Il pacchetto deve essere installato sullo staging prima di certificare la nuova copertura reale. Nessuna installazione sul live.

G07 resta PARTIAL per la verifica dell’inventario corretto installato, copertura shared/CPT pertinente e matrice visuale completa. C e il ciclo CSS con purge hanno ora evidenze positive; non sono più blocchi senza causa identificata.
